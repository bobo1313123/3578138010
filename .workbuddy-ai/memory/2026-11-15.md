## 人物文件格式统一（秘鲁 / 玻利维亚）
- 以 `common/characters/HYD characters.txt` 作为模组人物文件的「标准格式」样板。
- 用一次性脚本 `hoi4fmt.py`（临时目录）对 `common/characters/PER.txt` 做**纯空白/缩进规范化**：`key = value` 统一空格、tab 分级缩进、`traits` 多行块内缩进对齐；注释行（含注释掉的代码块）保持原样。
- 校验手段：去除全部空白字符后逐字比对 → 完全相同，说明只有空白变化，语义零改动；括号平衡 0；CRLF 与无 BOM 保持不变。
- `BOL.txt` 本身已是 HYD 风格，脚本运行后 0 行变化。
- PER 的 `instance = { allowed = { has_dlc = ... } }` 结构**保留未拆平**，因为它是 DLC 分支语义，不是排版。
